🧠 Data Structures & Algorithms (DSA) Concept Map

Algorithm / Structure File in src/ Time Complexity Real-World Role in ShopKart
Merge Sort sort.c O(n log n) [Stable] Default catalog sorting (multi-key preserve)
Quick Sort sort.c O(n log n) avg Catalog alternative sort with randomized pivot
Binary Search search.c O(log n) Price-range filtering (min/max boundary slice)
Trie (Prefix Tree) search.c O(L) query length Instant search query autocomplete & suggestions
Hash Table hashmap.c O(1) average Session token validation & user email auth
Stack (LIFO) stack.c O(1) push/pop Shopping Cart "Undo Remove" transaction history
Circular Queue queue.c O(1) FIFO "Recently Viewed Products" carousel (capped at 10)
Linked List linkedlist.c O(1) insert Dynamic user wishlist node additions & deletions
Min/Max Heap heap.c O(n log k) Extracting "Top 10 Deals" & "Highest Rated"
Binary Search Tree bst.c O(log n) avg In-order price indexing for range queries
