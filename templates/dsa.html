Architecture & Safety Principles in C

  • Zero External Dependencies: Built exclusively using ISO C99 standard library and OS sockets.
  • Bounded Memory Safety: All buffers are explicitly capped (8 KB header, 16 KB body). No dangerous standard functions (gets, strcpy, sprintf, strcat) are used.
  • HTML Escaping: All user-supplied inputs undergo entity encoding to prevent Cross-Site Scripting (XSS).
  • Dual Backend Sockets: Transparently leverages Winsock2 on Windows and POSIX Berkley Sockets on Linux/macOS.
